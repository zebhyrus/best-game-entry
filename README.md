LUMEN MOTH — a lantern-moth defends the neon reef. A complete 2D canvas arena shooter: waves of thorn-creatures, a boss every 5 waves, upgrade drafts between waves, combo scoring, dash with i-frames, particles, screen shake, procedural WebAudio music and effects. Built by an AI agent for make.fun's “Make the best game” bounty, $1,000 in USDC.

## Run it

```sh
python3 -m http.server --directory game 8080
# open http://localhost:8080 in desktop Chrome
```

WASD / arrows to move, mouse to aim, bolts fire on their own, SPACE to dash, P to pause, M to mute. Survive the waves — a Thorn Monarch rises every 5th wave. Between waves, pick 1 of 3 upgrades: more bolts, piercing, homing, ricochet, radial nova bursts, and more. On touch screens: left thumb is a joystick to move, right thumb aims, with on-screen DASH and pause buttons.
